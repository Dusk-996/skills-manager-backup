# DevOps 中文技能路由

按真实任务选择最多 1～3 个相关技能，说明各自承担的工作后继续执行。运维任务以 `devops-skill-router-zh` 为首选；通用内容任务使用本索引中的对应入口。

1. 读取 [已安装技能中文索引](references/skills-zh-index.md)，并与当前会话提供的技能目录核对。
2. 运维项目优先 DevOps 定制流程；通用开发才选择相应 Superpowers 流程。
3. 索引只是候选映射。若入口未在当前环境提供，改用实际可用的技能或工具，不推荐已删除入口，不把插件缓存当成已加载技能。
4. 继承用户的操作系统、国内网络、Shell 优先及生产变更要求。危险操作先说明影响，执行前准备备份、验证和回滚；已有明确授权不重复询问。
5. 明确任务可直接进入工作，不要求用户阅读完整技能列表。只有信息缺失会改变结果时才补问。

输出示例：`建议使用：skill-name。原因：当前任务需要……。` 只在确有分工时添加搭配技能。
