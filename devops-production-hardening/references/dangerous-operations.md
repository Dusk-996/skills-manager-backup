# 危险操作门禁

涉及以下操作时，必须先提醒并输出完整执行方案：

- 删除文件或目录，尤其是 `rm -rf`。
- 清空或迁移数据库。
- 重启 Docker、containerd、Nginx、MySQL、K8s 核心组件。
- 修改防火墙、安全组、iptables、nftables。
- `kubectl delete`、批量删除 Pod/PVC/Namespace。
- `docker system prune`、清理镜像/卷/网络。
- 修改生产配置、证书、Ingress、核心服务端口。

## 固定输出

```markdown
## 影响范围
说明会影响哪些主机、服务、端口、数据、用户。

## 执行前备份
列出具体备份命令和备份文件位置。

## 执行步骤
逐步执行，危险命令前加确认条件。

## 验证命令
列出服务状态、日志、端口、接口、数据校验命令。

## 回滚方案
说明如何恢复配置、数据、服务和镜像/二进制版本。

## 生产环境注意事项
说明执行窗口、通知、权限、审计和监控观察点。
```
