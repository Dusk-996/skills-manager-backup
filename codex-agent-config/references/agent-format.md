# 角色格式与兼容检查

核对日期：2026-11-15。运行环境会更新；使用时以当前已安装版本和官方文档为准。

官方资料：[Codex 子代理](https://learn.chatgpt.com/docs/agent-configuration/subagents)、[配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。

当前独立自定义代理文件位于项目 `.codex/agents/` 或个人 `$CODEX_HOME/agents/`，扩展名为 `.toml`。每份文件必须定义 `name`、`description`、`developer_instructions`。名称以文件内容为准，不能只检查文件名。

| 内容 | 处理 |
|---|---|
| 角色名称、适用任务、执行指令 | 三个必填字符串，不能空白 |
| 模型及推理 | 默认不填；用户明确要求时验证可用组合 |
| 只读或不执行部署 | 写入角色行为约束；不能声称建立了权限隔离 |
| 沙箱、审批、提供商、MCP | 从父会话继承；不放进角色文件尝试覆盖 |
| 缩减能力的可选字段 | 只在任务需要时按当前官方格式核对，不批量添加开关 |

自定义名称与 `default`、`worker`、`explorer` 等内置名称相同可能遮蔽内置角色。已有同名项时先确认用户是更新它，还是确实需要另一个角色。

检查器不是 Codex schema。通过只说明基础静态检查通过；它不会检测所有未知字段，也不会启动子代理、探测账号模型权限或改变任何配置。

如果本机版本不支持当前独立文件格式，报告实际版本和缺失能力，保留候选文件；不要自动改用网上旧版角色注册写法或升级客户端。
