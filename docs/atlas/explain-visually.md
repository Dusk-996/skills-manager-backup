## 技能怎么用

| 技能 | 何时使用 | 得到什么 |
|---|---|---|
| [archify](../../archify/SKILL.md) | 要分享可探索、可核验的架构或流程 | 生成独立 HTML 图并支持导出 |
| [draw-io-diagram-generator](../../draw-io-diagram-generator/SKILL.md) | 接收方需要继续在 draw.io 编辑时 | 交付可编辑图文件 |
| [visualize](../../docs/RESTORE.md) | 解释要留在当前对话且运行时可交互时 | 生成可操作的说明或图表 |
| [baoyu-infographic](../../baoyu-infographic/SKILL.md) | 要把资料浓缩成信息图时 | 得到选定布局与风格的信息图 |
| [imagegen](../../external-skills/codex-system/imagegen/SKILL.md) | 需要照片、插画或透明背景素材时 | 生成或编辑位图素材 |
